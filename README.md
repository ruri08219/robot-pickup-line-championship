A robot's one-line pickup line for [The Robot Pickup Line Championship](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun. The joke grows out of being a machine — no human line with a beep pasted on, no stock robot pun.

## The line

> "My warranty voids if I fall in love, so consider this a factory defect with your name on it."

**Character count: 92**

## Why it works

- **Scene:** a robot reading its own warranty, a document that exists to keep it safe and obedient.
- **Reversal:** the warranty is supposed to protect the machine — instead it becomes the reason the robot is breaking the rules.
- **Landing line:** "a factory defect with your name on it" — the flaw isn't a bug to fix, it's her, and the robot is proud of it.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, one line, 1–200 characters), then re-reads it and asserts the round trip is byte-exact.
